# 🌤️ Weather Now

A simple weather dashboard built with HTML, CSS and JavaScript. It uses the free Open-Meteo API, so no API key is needed.

**Live demo:** https://mokshi-25.github.io/weather-now/

## Features

- Search weather by city name
- 📍 "My location" button for your current location
- Current temperature, feels like, humidity and wind speed
- 5-day forecast with icons

## Built with

- HTML, CSS, JavaScript
- Open-Meteo API (weather and city search)
- BigDataCloud (finds your town name)

## Run locally

Open the folder in a code editor and use a simple local server, or visit the live demo above.
